# 🔐 GPG 签名提交 — 简体中文

本指南帮助你在本地创建 OpenPGP/GPG 签名密钥，把公钥添加到 GitHub，并为所有本地 Git 仓库启用签名，从而在 GitHub 上看到 `Verified` 标记。
