# Contributing

Thanks for helping keep this small guide useful.

Useful contributions include:

- technical corrections;
- macOS, Linux distribution, Windows, or Gpg4win changes;
- GitHub UI changes;
- translation corrections or additional languages;
- accessibility improvements.

Please keep the project Markdown-only and keep commands grounded in current official documentation. Do not add personal fingerprints, private keys, passphrases, credentials, or machine-specific paths. When a platform command changes, update the English guide first and keep every translation technically aligned.

Open an issue or pull request with a short explanation of the change and the official source that supports it.
